# Gym Empire — Navigation

## Objective

Create a navigation system that feels modern, restrained and professional.

The navigation must support the application without becoming the visual focus.

## Desktop

Use the existing application routes.

Organize them conceptually around:

### Primary

- Dashboard
- Workouts
- Progress

### Secondary

- Exercises
- History
- Calendar

### Utility

- Settings
- Account

Do not create new routes unless the application already requires them.

## Active state

The active navigation item must be immediately recognizable.

Use a combination of:

- typography weight;
- subtle background;
- small accent indicator;
- contrast.

Avoid oversized saturated pills.

## Sidebar

The sidebar should be visually quieter than the main content.

The content area should feel dominant.

Avoid:

- huge navigation blocks;
- excessive separators;
- excessive badges;
- decorative containers;
- unnecessary nested surfaces.

## Mobile

Mobile navigation must prioritize the most important destinations.

Do not simply compress the desktop sidebar.

Use the existing routing model.

Secondary destinations can be moved into:

- a menu;
- settings;
- contextual navigation.

## Icons

Use one coherent icon system.

Icons must support recognition.

Do not add icons purely for decoration.

Icon-only controls require accessible labels.

## Routing safety

Before modifying navigation:

1. inspect all routes;
2. search navigation references;
3. search active-state logic;
4. search redirects;
5. inspect mobile navigation.

Do not break routing.
