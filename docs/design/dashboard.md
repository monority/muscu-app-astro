# Gym Empire — Dashboard Redesign

## Objective

The dashboard is the primary visual proof of the redesign.

It must be substantially different from the current composition.

## Do not preserve the existing layout automatically

Do not start from:

- three KPI cards;
- another row of cards;
- chart card;
- recent activity cards.

This pattern is exactly what makes the application feel generic.

## Dashboard questions

The dashboard should answer:

1. Where am I?
2. How am I progressing?
3. What have I done?
4. What should I do next?

## Primary metric

Use one or two major metrics as visual anchors.

Possible data:

- weekly volume;
- workouts completed;
- training frequency;
- progression;
- personal records.

Use real application data.

Never invent data.

## Composition

A possible conceptual structure:

Page heading

Large performance metric        Next workout

Progression / chart

Recent training

Secondary statistics

This is not a mandatory layout.

Create the best composition based on the actual data available.

## Important

The dashboard should use whitespace as part of the design.

Do not fill every empty area with cards.

## Charts

Charts should feel integrated into the page.

Avoid:

- unnecessary borders;
- unnecessary axes;
- excessive labels;
- chart-container-within-card-within-section.

Prefer:

- strong data line;
- useful labels;
- clear context;
- restrained visual treatment.

## Recent workouts

Recent activity should be easy to scan.

Prefer:

- compact rows;
- separators;
- typography;
- useful metrics.

Do not automatically place every row inside a large card.

## Next workout

When a next workout exists, it should have clear priority.

The primary action should be obvious.

Example:

NEXT SESSION

PUSH

START WORKOUT

Use the application's real workout data.

## Responsive

Desktop may use asymmetric composition.

Mobile should prioritize:

1. primary metric;
2. next action;
3. progression;
4. recent training;
5. secondary information.

Do not simply stack desktop cards vertically.

## Final test

Compare the new dashboard to the old dashboard.

If the structure is still recognizable as the same card grid, redesign the composition again.
