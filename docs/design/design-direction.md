# Gym Empire — Design Direction

## 1. Major redesign requirement

This is a STRUCTURAL visual redesign.

Do NOT simply polish the existing interface.

The final interface must look materially different from the current application.

A before/after screenshot of the dashboard must clearly demonstrate a redesign.

If the result can be described as:

> "the same UI with better colors"

the redesign has failed.

---

# 2. Creative direction

Target:

> Premium performance interface.

Conceptual references:

- Freebuff
- The Signal
- Men in Black
- Linear
- Whoop

These are references for principles only.

Do not copy:

- layouts;
- branding;
- colors;
- components;
- illustrations;
- animations.

---

# 3. Visual concept

## PERFORMANCE DATA IN MOTION

The interface should combine:

- strong typography;
- large performance metrics;
- editorial composition;
- data visualization;
- subtle atmospheric depth;
- restrained motion;
- precise controls.

---
