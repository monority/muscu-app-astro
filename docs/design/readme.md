# Gym Empire — Design System & Refactor

This directory is the source of truth for the visual and UX redesign of Gym Empire.

The objective is NOT to polish the existing interface.

The objective is to create a clearly recognizable, professional and modern product while preserving the existing business logic and functionality.

## Critical principle

The redesign must be visually substantial.

Changing only:

- colors;
- shadows;
- border radius;
- spacing;
- gradients;
- hover effects;

does NOT constitute a redesign.

The structure, composition, hierarchy and visual language must evolve.
